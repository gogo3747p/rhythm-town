方法二：即時雲端同步（Firebase）

第一次使用：怎麼建立免費的 Firebase 資料庫？
  1. 開專案：用電腦打開 console.firebase.google.com，用 Google 帳號登入。按「建立專案／Create a project」，名稱打 rhythm-town（隨意），勾選同意條款按「繼續」。看到 Gemini、Google Analytics 的開關都可以關掉，最後按「建立專案」，等一下再按「繼續」。
  2. 找到資料庫：左側選單找「Databases & Storage（資料庫與儲存空間）」→「Realtime Database」。舊版畫面可能在「建構／Build」底下。按「建立資料庫／Create database」。
  3. 選位置：「Realtime Database 位置」選「新加坡 Singapore (asia-southeast1)」，離台灣最近，按「下一步」。
  4. 選規則模式：選「以鎖定模式啟動／Start in locked mode」，按「啟用／Enable」。不要選測試模式，測試模式 30 天後會自動鎖起來。
  5. 改規則：上方點「規則／Rules」分頁，把框裡原本的文字全部刪掉，貼上下面這段，再按右上角藍色的「發布／Publish」：
  6. 複製網址：點回「資料／Data」分頁，資料區最上方有一行 https:// 開頭的網址（旁邊有連結圖示），例如 https://rhythm-town-1a2b3-default-rtdb.asia-southeast1.firebasedatabase.app。整行複製，最後面不要多帶 / 或其他文字。
  7. 連線：回到這個畫面，把網址貼到「Firebase 資料庫網址」，自己取一個房間代碼（英文、數字、- 或 _，4 個字以上），按「連線」。看到 🟢 就成功了。
  8. 平板加入：在電腦按「產生平板連線碼」，用 LINE 或 Google Classroom 傳到平板，在平板打開同一個畫面，貼到「匯入」框，按「讀取」再按「連線」。

出現 🔴 時：確認規則有按「發布」、網址整行貼對、遊戲是用 GitHub Pages 網址（https 開頭）開啟，學校網路沒有擋 firebasedatabase.app。

知道網址和房間代碼的人都能修改進度，所以班級和組名請不要用學生的真實姓名。遊戲要用 GitHub Pages 網址（https 開頭）開啟，才能連到 Firebase。
